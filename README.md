## About me

I'm Oluwaferanmi, a software engineer based in Nigeria with more than four years of experience. I build web applications and mobile apps for businesses, students, and everyday users.

My work includes e-commerce websites, management systems, educational apps, and secure online platforms. I work on both the frontend and backend, from designing interfaces to building APIs and connecting databases.

I mainly use TypeScript, JavaScript, Python, React, Next.js, React Native, Node.js, FastAPI, PostgreSQL, Supabase, and Tailwind CSS.

## A few things I've built

### [Ona AI](https://github.com/Nouth-Ayinla/Ona)

An academic and career guidance app for Nigerian students. It provides personal roadmaps, useful recommendations, and access to important information even when an internet connection is unreliable.

`React Native` / `Expo` / `Next.js` / `Supabase` / `Gemini AI`

### [The Threadly Nest](https://oluwaferanmiportfolio.netlify.app/#projects)

A mobile app that helps fashion houses manage customer measurements, fittings, orders, media, and consultations without relying on scattered paper records.

`React Native` / `Expo` / `TypeScript` / `Cloudflare R2` / `Gemini AI`

### [NACOSS E-Voting System](https://nacossfuta.com.ng/)

An anonymous voting platform with one-time access codes, auditable ballots, two-factor protection for administrators, and live election results.

`Next.js` / `TypeScript` / `Python` / `PostgreSQL` / `Node.js`

You can find more of my work on my [portfolio](https://oluwaferanmiportfolio.netlify.app/#projects) or in my [repositories](https://github.com/Nouth-Ayinla?tab=repositories).
